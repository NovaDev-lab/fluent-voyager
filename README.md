# Fluency Compass

Take Duolingo's current language catalog, AI conversation features, and course-depth signals, then map what learners can actually accomplish in each language. Build an explorer that shows CEFR depth, writing system difficulty, speaking-practice availability, grammar density, and which outside resources someone would need to go from streaks to real-world fluency. Add a mode for linguistics nerds that clusters languages by morphology, script, and transfer difficulty so people can choose the smartest next language. Deploy it as a website.
